  STEP 1: Install Dependencies
  ────────────────────────────────────────────────────────────

  cd web-ui/backend
  pip install -r requirements.txt

  cd ../frontend
  npm install
  cd ..

  ────────────────────────────────────────────────────────────

  # Terminal 1: Backend
  ./start_backend.sh

  ────────────────────────────────────────────────────────────

  http://localhost:3000
