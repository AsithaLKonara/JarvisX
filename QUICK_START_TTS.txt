🚀 ENABLE TTS IN 30 SECONDS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Enable TTS:
     echo "ENABLE_TTS=true" >> .env
     echo "TTS_ENGINE=pyttsx3" >> .env

  2. Start Jarvis:
     python3 main.py

  3. Test it:
     You: tts test
     🔊 Jarvis speaks!

  4. Chat with voice:
     You: Hello Jarvis
     [Response appears + Jarvis speaks it!] 🎤

🎯 VOICE COMMANDS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  
  During chat, type:
  • "tts on"    - Enable voice output
  • "tts off"   - Disable voice output  
  • "tts test"  - Test TTS (Jarvis speaks a test message)
  • "status"    - Show TTS status
