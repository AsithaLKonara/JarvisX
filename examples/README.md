# JarvisX V2 CLI Examples

This directory contains example scripts demonstrating common use cases for the JarvisX V2 CLI.

## Examples

### 1. Training Workflow (`training_workflow.py`)
Complete training workflow from start to deployment:
- Start training job
- Monitor status
- View logs
- Evaluate model

**Usage:**
```bash
python3 examples/training_workflow.py
```

### 2. Business Automation (`business_automation.py`)
Business operations workflow:
- Add client
- Generate invoice
- Generate reports
- Export data

**Usage:**
```bash
python3 examples/business_automation.py
```

### 3. Voice Automation (`voice_automation.py`)
Voice command examples:
- Parse voice commands
- Interactive voice mode
- Voice-enabled commands

**Usage:**
```bash
python3 examples/voice_automation.py
```

### 4. Cloud Deployment (`cloud_deployment.py`)
Cloud deployment workflow:
- Connect to cloud space
- Check status
- Deploy model
- Monitor deployment

**Usage:**
```bash
python3 examples/cloud_deployment.py
```

## Running Examples

All examples require:
- Python 3.11+
- JarvisX V2 installed
- CLI available via `python3 -m cli.main`

## Customization

Modify the examples to fit your specific use cases:
- Update paths and configurations
- Add your own workflows
- Integrate with your automation scripts
