# 🤖 Jarvis X V2 - Web Interface

Interactive web UI for Jarvis X V2 AI Assistant with 3 switchable themes.

## Features

- **3 Visual Themes:** Professional, Terminal, Avatar
- **Real-time Chat:** WebSocket-powered instant messaging
- **7 Operational Modes:** Engineer, System, Designer, Editor, Business, Casual, Career
- **System Monitoring:** Live CPU, RAM, Disk stats
- **Voice Output:** TTS integration
- **Lip-Syncing Avatar:** 2D avatar synced with voice (Avatar theme)

## Tech Stack

- **Frontend:** React 18 + TailwindCSS + Vite
- **Backend:** FastAPI + WebSockets
- **AI:** Custom Mistral 7B (137K examples)

## Usage

Visit the Space URL and start chatting with Jarvis!

Switch themes using the theme selector in the header.
