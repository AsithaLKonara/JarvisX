┌──────────────────────────────────────────────────────────────────────────┐
│  🚀 METHOD 1: Model Already on HF Hub                                    │
└──────────────────────────────────────────────────────────────────────────┘

If your model is at: https://huggingface.co/YOUR-USERNAME/your-model

# Step 1: Install dependencies (2 minutes)
pip install transformers peft bitsandbytes torch accelerate

# Step 2: Test connection (3 minutes first time)
python3 scripts/connect_hf_model.py \
  --model YOUR-USERNAME/your-model \
  --test

# Step 3: Configure system
python3 scripts/connect_hf_model.py \
  --model YOUR-USERNAME/your-model \
  --configure

# Step 4: Use it!
export HF_MODEL_ID="YOUR-USERNAME/your-model"
python3 training_gui.py

✅ DONE! Your HF model is connected!


┌──────────────────────────────────────────────────────────────────────────┐
│  📤 METHOD 2: Upload Local Model First                                   │
└──────────────────────────────────────────────────────────────────────────┘

If your model is ONLY on your computer:

# Step 1: Install HF CLI
pip install huggingface-hub

# Step 2: Login to Hugging Face
huggingface-cli login
# Enter token from: https://huggingface.co/settings/tokens

# Step 3: Upload (1-5 minutes for 26MB LoRA)
python3 scripts/connect_hf_model.py \
  --upload \
  --repo YOUR-USERNAME/jarvis-mistral-7b-lora \
  --local-path "jarvis-llm-brain-final fine tune 7B model"

# Step 4: Test connection
python3 scripts/connect_hf_model.py \
  --model YOUR-USERNAME/jarvis-mistral-7b-lora \
  --test

# Step 5: Use it!
export HF_MODEL_ID="YOUR-USERNAME/jarvis-mistral-7b-lora"
python3 training_gui.py

✅ DONE! Model uploaded and connected!


┌──────────────────────────────────────────────────────────────────────────┐
│  ⚡ METHOD 3: Use HF Inference API (No Local Setup!)                     │
└──────────────────────────────────────────────────────────────────────────┘

Fastest way! No download needed!

# Step 1: Upload model (if not already on HF Hub)
# See Method 2 above

# Step 2: Get HF API token
# Go to: https://huggingface.co/settings/tokens
# Create "Read" token

# Step 3: Set environment variables
export HF_MODEL_ID="YOUR-USERNAME/your-model"
export HF_API_TOKEN="your-token"

# Step 4: Use Inference API (add to training_gui.py):
pip install huggingface-hub

# The system will auto-use Inference API!
python3 training_gui.py

✅ DONE! No local setup needed!

┌──────────────────────────────────────────────────────────────────────────┐
│  📊 WHAT HAPPENS                                                          │
└──────────────────────────────────────────────────────────────────────────┘

METHOD 1 (Local):
  1. Downloads Mistral-7B base (~14GB, one-time)
  2. Loads with 4-bit quantization (→ 3.5GB RAM)
  3. Applies your LoRA adapter from HF
  4. Ready! Inference in 2-4s

METHOD 2 (Upload):
  1. Uploads your 26MB adapter to HF Hub
  2. Then same as Method 1
  3. Benefit: Accessible from anywhere!

METHOD 3 (Inference API):
  1. Uses HF servers (no local download!)
  2. Instant start
  3. Fast inference (1-2s with GPU)
  4. Free for public models

┌──────────────────────────────────────────────────────────────────────────┐
│  🐛 TROUBLESHOOTING                                                       │
└──────────────────────────────────────────────────────────────────────────┘

Issue: "Model not found on HF Hub"
Solution: Check model ID, make sure it's public or you have access

Issue: "Out of disk space"
Solution: Use Inference API (Method 3) - no download needed!

Issue: "Out of memory"
Solution: Using 4-bit quantization already! Close other apps.

Issue: "Download too slow"
Solution: Use Inference API or wait for first download (one-time)
